ダンジョン脱出
剣で戦い、盾で守れ！ 敵や障害物を突破して、制限時間内にゴールを目指す一人称アクションゲームです。

「操作を覚える」「腕試し」「ボスに挑戦」の全3ステージ。初めての方は「操作を覚える」から遊んでみてください。

| 操作 | キー・マウス |
|---|---|
| 移動 | W・A・S・D |
| 視点移動 | マウスを動かす |
| ジャンプ | スペース |
| 攻撃 | J／左クリック |
| ガード | K／右クリック |
| 視点を戻す | C |
| ステージをやり直す | R |
| 一時停止・操作方法の確認 | Esc |

攻略のポイント
正面からの攻撃は盾でガードできます。ただし、ガード中は移動が遅くなり、攻撃と同時には使えません。敵の攻撃を防いだら、隙を見て反撃しましょう！

足元の矢印がゴールの方向を示しています。体力がなくなるか、時間切れになるとゲームオーバーです。

ボスステージでは、武器の構えと光に注目！ 攻撃後に緑の床リングが出たら反撃のチャンスです。ボスを倒すと大きな金色の鍵が出現します。触れて拾い、鍵のかかったゴールを開けて脱出しましょう！

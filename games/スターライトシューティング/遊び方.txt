スターライト・ディフェンダー 日本語版 v8 — 操作ガイド

キーボードで操作するゲームです。

【起動】
1. ZIPを解凍します。
2. Python 3が使えるターミナルで、このフォルダの serve.py を実行します。
   python3 serve.py
3. ブラウザで http://127.0.0.1:8769 を開きます。
4. ゲーム画面をクリックするとキーボード操作ができます。
※ index.html のダブルクリック（file://）では起動できません。

【タイトル画面】
Enter / Space /「出撃する」をクリック：最初の強化を選ぶ画面へ進みます。

【戦闘中】
WASD / 矢印キー：移動
Z / Spaceを長押し：初期3Wayで連続射撃。翼部砲で5Wayに強化
Shiftを押しながら移動：通常の45%の速度で精密移動
X：ボムで敵弾を消し、範囲攻撃（開始時2発、所持上限5発）
Esc：一時停止 / 再開

当たり判定は機体中央の小さな白い点だけです。
点の周囲の黒い縁や翼には判定がありません。
被弾直後は機体が点滅し、短時間無敵になります。白い点は点滅中も表示されます。
右上の「体力」と残量表示、下部のボム・盾の残数を確認してください。
盾がある場合は、1回の被弾につき盾を1つ消費して体力の減少を防ぎます。

【強化画面】
1 / 2 / 3（テンキーも可）/ カードをクリック：強化を1つ選んで決定
R /「再抽選」をクリック：資源を使って3つの選択肢を引き直す
再抽選の費用は初回40、以降20ずつ増えます。資源が足りないと使えません。
出撃前は無料で異なるスキルを2種類、1つずつ選ぶと戦闘開始。1つ目では戦闘は始まりません。ステージ突破後は無料の強化を選んでショップへ進みます。
強化を選んでいる間は戦闘が止まります。
※ 戦闘中にRを押しても再抽選はできません。

【ステージ1～4突破後：補給ショップ】
無料の強化1つを獲得した後、ランダムな3商品から追加でお買い物できます。
1 / 2 / 3（テンキーも可）/ 商品カードをクリック：表示価格でスキルを1段階購入
各商品1回、複数購入可。購入済み・資源不足・ボム満タンの商品は購入できません。
R /「商品入替」をクリック：資源を消費して3商品をすべて入れ替えます。
商品入替と無料強化の再抽選は共通費用（初回40、以降20ずつ増加）。購入費用は別です。
Enter /「第○ステージへ」をクリック：買い物を終えて次の面へ進みます。
購入しなくても進めます。買い物中は戦闘が止まり、資源は次の面へ持ち越せます。

初段階の価格（資源）：
30：高機動スラスター、予備ボム
40：回収ドローン、過負荷コア
45：自動装填装置
50：位相貫通弾、シールド蓄電器
55：強化装甲
60：プラズマ炉
75：翼部砲
所持段階ごとに価格＋20。例：プラズマ炉 60 → 80 → 100。
購入したスキルはこの出撃中ずっと有効です。上限のスキルは商品に出ません。
全スキルが上限なら無料選択を飛ばし、ショップの次の面ボタンで進めます。

【アイテム】
S（紫）：資源+10。スキルの追加購入と再抽選・商品入替に使用します。
O（黄）：連射強化。基本6秒、延長する強化あり。重ね取り上限15秒。
D（青）：盾+1。所持上限を超えた分は資源+10に変わります。
+（緑）：体力+1。満タンなら資源+10に変わります。
B（橙）：ボム+1。所持上限を超えた分は資源+10に変わります。

【進行と持ち越し】
全5ステージです。5体のボスを倒すとクリアです。
出撃前のスキルは無料で2種類。ステージ1～4のボス撃破後の無料強化は各1つです。
ステージ1の弾数は従来の1.15倍（基本弾20発につき追加弾3発）。発射間隔と弾速は従来どおり。
ステージ1～4のクリア報酬は資源20。無料強化の後、ショップで追加購入できます。
体力・装備・資源・ボム・盾は次のステージに持ち越します。
ステージ間の自動全回復はありません。一時的な連射強化は次の面で解除されます。

【進化するボス】
2面：双砲形態。3面：翼展開形態。4面：重装要塞形態。5面：最終形態。
後の面ほど武装と外装が増え、攻撃方法と固有スキルが変化します。
ボスの体力と弾幕量は、進化による強化後からさらに約2倍。
固有スキルは発動名と短い予告が出ます。横や背後、途中で向きが変わる弾にも注意。
体力半分以下で激昂し、固有スキルも発動します。

【結果画面：クリア / 作戦失敗】
R /「新たな出撃」をクリック：ステージ1からやり直す
T /「タイトルへ」をクリック：タイトルへ戻る
再出撃では装備・資源・進行状況をリセットし、体力3・ボム2から始まります。
ハイスコアは保存されます。

【終了】
ブラウザのゲーム画面を閉じ、起動したターミナルで Ctrl+C を押すと終了します。

【一般のWebサーバーへ配置する場合】
.brファイルに Content-Encoding: br を付け、.wasm.brには application/wasm、
.js.brには application/javascript を設定してください。
